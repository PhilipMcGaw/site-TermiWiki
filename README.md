# TermiWiki

Standalone source and build output for the historical TermiSoc Wiki.

- `source/` — the Obsidian vault, with Markdown pages at its root and referenced
  media under `media/`. Individual profiles are in `source/TermiPeople/`.
  Glossary-tagged pages are in `source/Glossary/`.
- `scripts/` — Quartz configuration, Apache rewrite rules, and maintenance tools.
- `site/` — generated static site; regenerated by the deployment script.

Run `scripts/deploy_termiwiki.sh` from this repository to build and publish the
site. It uses `rsync --delete` against the production TermiSoc web root, so it
should only be run when the generated output is ready to publish.
