# Post-History

# 2014/2015
in 2014 the university had us remove the server from the cupboard we did access it but didn't get around to doing anything with it, the next committee took it and when we tried to revive the society the following year when they failed to form a committee only a handful of things were returned some network switches, cables, a butchered LAN server missing a ssd and power supply, we lost an old terminal machine and the old server.

## 2015/2016
In 2015, it looks like TermiSoc suffered another demise, [Farrell](TermiPeople/matt_farrell.md) tried to resurrect it for 2016 - "As many of you are aware TermiSoc died last year and we need help bringing it back. We need 20 names and current student ID [sic] to get going again we have big plans but need this first."  -- https://www.facebook.com/groups/upsugamesociety/permalink/1281670855190640/
