On the 4th of August (ish) server|Area51's hard disk died completely, and unfortunately, no data can be recovered. I have rebuilt area51, and it's back online, but there are a few points you need to know:
- the last backup was 13 months ago
- any accounts made in the last year have been lost
- all society websites hosted on here have been lost, you will need to mail me to get them sorted
- no accounts have been added in an attempt to 'spring clean' the user list, if you are an ex-member, or a student at Plymouth university, email me with a request to restore/create your account. (subject to £2 membership for non-ex-members)

Mail me at pookey@pookey.co.uk and I'll sort all your problems out!


Hopefully next academic year, that's September 2003 we are going to try to revive Termisoc. So if you have any ideas about what we could offer students at Plymouth University other than the awesome flux ;) and web hosting please email me at moose@termisoc.org! Cheers, Moose.

Server Upgrade

Orange has been our secondary DNS server and our projects machine for a while now, but it's been playing up and we think it's time for a change. Apple is going to be upgraded (with some help from our sponsors, The Computer Shop @ Integrem) and the leftover bits will go to make a new, healthier, happier orange. November 2004

TermiSocial Blog Now Online!

As a new investment to the Termisocians, NanoHead (a.k.a. [Morris](TermiPeople/chris_morris.md)) has done us proud by creating The TermiSocial Journal. This Blog tries to give a member's view of what goes on in the Society, and prides itself on its piles of pictures. Go there now!

ASP is now supported!

Shockingly, Apple has fallen victim to some added features and now our Apache-powered web server now supports (as best we can) ASP! This means that anyone who used Microsoft-powered server-side code can now use it on Apple (This, of course, is not a perfect clone of ASP. Some code will not be compatible, but hey, it's a step forward)
