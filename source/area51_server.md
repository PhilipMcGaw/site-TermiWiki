# Area51 (server)

 Area51 - area51.termisoc.org

Area 51 was the main TermiSoc server, on which every member had an account on. It was used for serving webpages and e-mail.

Back in 1993, we thought the name "area51" was a pretty cool idea.
Spec:

Area51 Mk. 1

Built 1993

    Intel 486 DX 50
    8MB EDO SIMM memory
    LCD Speed display panel showing A51 but often mistaken for ASI 

Area51 Mk. 2

Built 1995

    Pentuim P120 processor
    4 x 16MB SIMMs
    6.4GB IDE hard disk
    NE2000 network card 

Became Prot in 1997
Area51 Mk. 3

Built 1997

    Pentium P200 MMX processor
    32MB DIMM, later upgraded to 128MB DIMM
    Intel Triton TX motherboard
    20GB ATA66 UDMA hard disk
    3.2GB UDMA hard disk
    3Com 3c509 network card 

Retired to make way for Area51 Mk.4 in 2000. Some parts used to make Banana.

Area51 Mk. 4

Built 2000

    Pentium III 800MHz Processor
    256MB RAM
    40GB IDE Hard Disk
    3com 3c509 network card 

Around about the 4th of August 2002, Area51 Mk. 4 experienced a hard disk crash and died completely. Unfortunately, no data could be recovered and the last backup was 13 months prior to the disaster. It was rebuilt by christian|Pookey. Source: [Wayback Machine](https://web.archive.org/web/20020923160203/http://termisoc.org/|The)

After some changes to the hardware renamed Apple in 2003/04.
