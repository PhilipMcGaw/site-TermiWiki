# Area51 (website)

Area51 is what the code running the TermiSoc website is commonly referred to as, as well as the website itself. It was originally written by [Hatton](TermiPeople/pete_hatton.md) and was mostly lost as a result of [david pithouse](TermiPeople/david_pithouse.md) backups. It was rewritten by [peter|Gem](TermiPeople/gemma_peter.md); her code was much less exciting but much more understandable and used all that fancy CSS and stuff.

Since then, there have been several plans to replace it with "Area52", an as-yet-unwritten system. It's possible that it'll be written in Ruby. Or Python. Or Perl, or a .NET language. If you're interested, give it a go. Suggestions that we use a system like Mambo/Joomla, Plone, Drupal, etc., rather than an in-house production, have been met with resistance. 

See also [(server)](area51_server.md).
