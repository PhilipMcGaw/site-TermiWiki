# TermiBot

TermiBot haunts [TermiChat](Projects/termichat.md), providing services such as URL shortening and generalised abuse.

## Author

Written by [bma](TermiPeople/ben_a_lee.md) in Ruby for some second-year coursework, it has proved a useful addition to the room. It is soon to be replaced by a Python version, for reasons unknown. You can find the source code for TermiBot on bma's [repo](https://web.archive.org/web/20101102141528/http://git.subvert.org.uk/bma/?p=projects/termibot.git;a=summary|git). The Python version is [here](https://web.archive.org/web/20101102141528/http://git.subvert.org.uk/bma/?p=projects/termibot2.git;a=summary|also).

## Usage
TermiBot is generally reactive, rather than responding to specific commands. For example, try appending "++" to a mention of a favourite topic, or putting a URL into your chat.
