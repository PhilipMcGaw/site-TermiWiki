# Jamie Pates

## TermiSoc

Jamie Pates's public LinkedIn profile records that he studied at the University of Plymouth from 2010 to 2014 and was involved with TermiSoc.[^1]

The same profile identifies several public software projects. His current GitHub account, `Cyanoxide`, contains React/TypeScript recreations of Windows XP, the Final Fantasy VII menu, and Final Fantasy VIII's Triple Triad game. These projects are not presented as TermiSoc projects, but provide useful identity corroboration for the surviving public profile.[^2][^3][^4]

## Public projects

- **React XP** — React and TypeScript recreation of Windows XP.[^2]
- **FF7 Menu Portfolio** — React and TypeScript recreation of the Final Fantasy VII menu.[^3]
- **Triple Triad React** — browser-based recreation of the Final Fantasy VIII Triple Triad minigame.[^4]
