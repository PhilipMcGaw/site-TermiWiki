SinisterOS is the name of the operating system being written by [Ben](../TermiPeople/ben_a_lee.md) and [SinisterSoftware](http://sinistersoftware.co.uk/).
## History
SinisterOS came about in late November 2005, when, during an argument on TermiList about operating systems and the latest Windows vulnerability, [Skippy](../TermiPeople/philip_mcgaw.md) commented "When you write an operating system, then try complaining more". [Ben](../TermiPeople/ben_a_lee.md) took this as a challenge and further discussion resulted in the agreement that SinisterOS would be a POSIX-compliant operating system for 64-bit (x86_64) processors, with the first full release in late 2012.

The first component of SinisterOS, the command interpreter WeirdSH (pronounced weird-ish) was released several days later, with more updates following shortly afterwards.
## Current Status
WeirdSH has been on hold for several months, due to problems porting to a 64-bit platform. It seems likely that the project will be taken over by Technologies.
