# Systems

**Please note this information was current on the publishing date but is now subject to the 2000/2001 budget.**

## Area51
[server](area51_server.md) - https://area51.termisoc.org

Area 51 is the main and new TermiSoc server, on which every member has an account. It is used for serving webpages and e-mail.

### Spec:
- Pentium P200 MMX processor
- 32MB DIMM, 128MB DIMM
- Intel Triton TX motherboard
- 20GB ATA66 UDMA hard disk
- 3.2GB UDMA hard disk
- 3Com 3c509 network card

## Prot
Prot - https://prot.termisoc.org

Prot is a dedicated machine for running our popular Eagles BBS based BBS [BBS](flux_bbs.md), as a result of this prot may also be accessed at https://flux.termisoc.org.

Very few shell accounts exist on this system.

### Spec:
- Pentuim P120 processor
- 4 x 16MB SIMMs
- 6.4GB IDE hard disk
- NE2000 network card

## Esra
Esra - https://esra.termisoc.org

Esra is the termisoc.org master DNS server.

### Spec:
- Pentium P75 processor
- 2 x 32MB SIMMs
- 6.4GB IDE hard disk
- NE2000 network card
