# CompSoc Breast Cancer Machine-Learning Workshop 2026

In collaboration with MedTech Society, CompSoc ran a two-session workshop on building a breast-cancer prediction model. The first session covered the medical context, Python fundamentals and exploration of a real breast-cancer dataset using scikit-learn. The second session developed the model further.
