The CD Library was a rather abortive project to build up a library of free and open-source software, mostly distributions, that could be borrowed by [TermiSoc](termisoc.md) members. The project was aborted for a number of reasons:
- The original library was [Daved](Glossary/daved.md)
- The web interface for the system was never completed (by cosser|danbjorn)
- The rise in the availability of decent internet connections rather made the library pointless 

Maybe if people without decent connections were in need of such software, then the library could be reinstated.
