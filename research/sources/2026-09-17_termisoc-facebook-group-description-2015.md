# TermiSoc Facebook-group description and committee, October 2015

## Source and retrieval

The project maintainer supplied a transcription of the TermiSoc Facebook-group description dated 12 October 2015 on 17 September 2026. It calls the group “The official group of TermiSoc” and links to `http://www.termisoc.org`.

## Direct evidence

The description lists the following officers:

| Role | Name |
| --- | --- |
| Chairman | Jamie Woods |
| Secretary | Eleanor Milner |
| Treasurer | Phil Akers |
| Safety Officer | Harriet Eldred |

## Interpretation

This is direct, date-specific evidence of the TermiSoc name and the four listed committee roles on 12 October 2015. It independently corroborates Jamie Woods’s chairmanship and gives a dated committee context for the other three existing member profiles.

The later 26 October 2016 group description identifies CGS as “formerly TermiSoc”, making the interval from October 2015 to October 2016 the current evidence-backed window for the re-brand.

An earlier 22 March 2015 executive photograph independently corroborates the roles of Woods, Milner, Akers, and Eldred, and adds Mike Jones (BCS Liaison), Callum Trounce (Technical Officer), and Mike “Ducky” Burgess (Events Secretary).
