# Nick Charlton — TermiSoc Python tutorial repository

## Source and retrieval

- **Repository:** <https://github.com/nickcharlton/termisoc-python-tutorial>
- **Owner:** `nickcharlton`
- **Retrieved:** 2026-09-19 through the public GitHub API and raw repository files.
- **Repository metadata:** created 2011-10-16, last pushed 2011-10-17, archived, default branch `master`.

## Direct evidence

The README calls the repository **TermiSoc Python Tutorial** and says its examples accompanied a talk given by Nick Charlton at TermiSoc to introduce programming with Python. It says the repository was forked from Ross Bearman's game example from the first year it was given, identified as academic year 2010–2011, and expanded for the tutorial.

The listed examples are `hello_world.py`, `hello_name.py`, `fibonacci.py`, `tweets.py`, and `adventure_game.py`. The README states that the copyright belongs to TermiSoc and its members, 2011, and gives an MIT licence.

The commit history includes commits by Nick Charlton on 16 October 2011 adding the examples and updating the README. Earlier commits by Ross Bearman in March 2011 develop the game example.

## Interpretation
