# Aaron Trevena — personal-site archaeology

## Source

Targeted examination of Aaron Trevena's current personal website and related preserved material, following the identification of Aaron as a TermiSoc Treasurer and organiser and co-founder of the Devon & Cornwall Linux User Group with Alex Charrett.

Primary source:

- https://www.aarontrevena.co.uk/

Supporting sources:

- https://www.mail-archive.com/search?f=1&l=london-pm%40lists.dircon.co.uk&o=newest&q=from%3A%22Aaron+Trevena%22
- https://github.com/hashbangperl/Autodia
- https://metacpan.org/pod/Autodia
- https://www.dcglug.org.uk/archive/2008/01/msg00076.html

## Direct evidence from Aaron's current site

Aaron's site identifies the **Devon & Cornwall Linux User Group** as an open-source project and states that it was **co-founded with Alex Charrett in 1999 as part of running the University of Plymouth Computing & Internet Society**. The site also says that the group now has an active mailing list and occasional Plymouth meetups.

The site's education section records a **BSc (Hons) Computer Systems & Networks at the University of Plymouth, 1995–2000**, and explicitly states that Aaron founded the Devon & Cornwall Linux User Group and was Treasurer of the computing society.

Source: Aaron Trevena personal website.

URL: https://www.aarontrevena.co.uk/

## TermiSoc-hosted personal web space

A much stronger historical lead comes from preserved London Perl Mongers mailing-list messages from 2001. Aaron's messages repeatedly carry the signature/link:

`http://termisoc.org/~betty`

This demonstrates that Aaron had personal web space hosted under the historical TermiSoc domain and used it publicly in 2001. The same archive contains multiple technical discussions in which Aaron published or discussed his own software projects.

Examples include:

- 10 April 2001: Aaron announced that he had uploaded **AutoDIAL** to his site, describing it as generating UML class diagrams from Perl scripts/modules and noting plans for additional language support.
- 12 April 2001: Aaron announced a new AutoDIAL release, referring to it as `DiaKiller`.
- 16 April 2001: Aaron discussed the re-release of AutoDIAL.
- 31 May 2001: Aaron discussed adding SQL/database-schema handling to AutoDIAL and described version 0.9 as supporting Perl and simple C++.

Source: London Perl Mongers archive, Aaron Trevena author search.

URL: https://www.mail-archive.com/search?f=1&l=london-pm%40lists.dircon.co.uk&o=newest&q=from%3A%22Aaron+Trevena%22

Confidence: **High** for the existence and public use of Aaron's `termisoc.org/~betty` personal web space in 2001. The archive evidence is particularly valuable because it is contemporaneous and independently preserved.

## AutoDia as a historical technical artefact

Aaron's current site identifies **AutoDia** as an open-source project. The surviving project repository states that AutoDia was originally created by Aaron Trevena and is an application for automatically generating documentation and UML-style diagrams from source code and schemas. The repository records Aaron as author and maintainer and dates the copyright to 2001.

MetaCPAN independently preserves the project and identifies Aaron Trevena as author/releaser; the current package documentation states that the project was copyrighted 2001–2007.

Sources:

- https://github.com/hashbangperl/Autodia
- https://metacpan.org/pod/Autodia

This is not itself evidence that AutoDia was a TermiSoc project. It is, however, useful contextual evidence of the sort of open-source software activity being carried out by a TermiSoc member immediately after his University period, and it provides another route into Aaron's historical online identity.

## Link to the later Devon & Cornwall LUG

The surviving Devon & Cornwall Linux User Group archive contains a 2008 message from Aaron using his `aarontrevena.co.uk` signature and identifying himself with the LUG mailing list. This is later than the founding period but provides continuity between Aaron's University-era Linux activity and the subsequently established LUG community.

Source: Devon & Cornwall LUG archive, 3 January 2008.

URL: https://www.dcglug.org.uk/archive/2008/01/msg00076.html

## Interpretation

Aaron's current website is more useful than it first appears because it provides a bridge between three otherwise separate archaeological strands:

1. **TermiSoc / University of Plymouth, 1995–2000** — Aaron identifies himself as Treasurer of the computing society.
2. **Devon & Cornwall Linux User Group, founded 1999** — Aaron states that he co-founded the LUG with Alex Charrett as part of running the University computing and Internet society.
3. **Historical TermiSoc web infrastructure, 2001** — preserved external mailing-list messages show Aaron using `termisoc.org/~betty` as his personal public web address.

The third strand is particularly important because it confirms that TermiSoc provided individual hosted web space to at least one member, and that such pages were used for software publishing and external community activity. This should be cross-referenced with the existing David Pithouse evidence for `termisoc.org/~moose` and the broader TermiSoc hosting/infrastructure archaeology.

The evidence does **not** establish that AutoDia was developed as a TermiSoc project. It should remain a personal project associated with a TermiSoc member unless direct evidence connects it to the society.

## Research leads

1. Archive `termisoc.org/~betty` through the Internet Archive and other historical web archives.
2. Search for references to `~betty`, `Betty @ termisoc.org`, and Aaron Trevena in other mailing-list archives.
3. Search the historical TermiSoc domain for other `~username` pages and correlate those usernames with known members.
4. Investigate whether the old TermiSoc server hosted a directory/index of personal pages.
5. Investigate `lug.termisoc.org` and surviving Devon & Cornwall LUG material for Alex Charrett, Aaron Trevena and additional early TermiSoc members.
6. Search old copies of Aaron's site for photographs, committee information, society events, Linux meetings, accommodation/house references or links to other TermiSoc members.
7. Preserve the AutoDia project as a contextual technical artefact and use its historical links/metadata to identify further contemporaneous pages.

## Confidence summary

- Aaron Trevena was Treasurer of the University of Plymouth computing society — **High**, based on Aaron's current personal site and LinkedIn.
- Aaron and Alex Charrett co-founded the Devon & Cornwall Linux User Group in 1999 while running the University computing and Internet society — **High**, based on Aaron's personal site; independently corroborated by contemporary LUG/Linux-directory evidence elsewhere in the project.
- Aaron used `termisoc.org/~betty` as personal public web space in 2001 — **High**, based on multiple preserved contemporary London Perl Mongers messages.
- AutoDia was Aaron's open-source software project from around 2001 — **High**, based on surviving project and package records.
- AutoDia was a TermiSoc project — **Unverified**; no direct evidence found in this pass.

## Publication impact

The person page for Aaron Trevena should cite the TermiSoc Treasurer role, the 1999 LUG co-founding, and the `termisoc.org/~betty` hosting evidence separately. The historical personal web-space evidence should also feed the infrastructure archaeology because it provides direct evidence for member-hosted content on the TermiSoc domain.
