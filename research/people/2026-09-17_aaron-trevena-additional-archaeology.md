# Aaron Trevena — additional site and web archaeology

## Source

A targeted search was conducted on 2026-09-17 for additional historical material connected with Aaron Trevena, TermiSoc, `termisoc.org/~betty`, the Devon & Cornwall Linux User Group, and Aaron's open-source work.

## Direct evidence

### TermiSoc personal web space: `~betty`

Multiple contemporaneous London Perl Mongers messages by Aaron Trevena from January–June 2001 carry the signature:

`http://termisoc.org/~betty` / `Betty @ termisoc.org`

This independently confirms that Aaron had a personal web-space address under the TermiSoc domain in 2001. The repeated use across many messages makes this stronger than a single isolated URL occurrence.

Source: London Perl Mongers archive, Aaron Trevena message index.

URL: https://www.mail-archive.com/search?f=1&l=london-pm%40lists.dircon.co.uk&o=newest&q=from%3A%22Aaron+Trevena%22

Examples include messages dated 2 January, 3 January, 12 January, 20 January, 21 January, 2 February, 19 February, 21 February, 26 March, 28 March, 10 April, 12 April, 16 April, 31 May and 3 June 2001.

### Aaron's software work in 2001

The same contemporary archive documents Aaron developing and publishing software during this period. In April 2001 he described uploading `AutoDIAL`, a Perl tool for generating UML class diagrams from scripts/modules, to `droogs.org/autodial/`. Subsequent messages describe a new release and development towards support for C++ and database-schema generation.

Source: London Perl Mongers archive, Aaron Trevena messages, April–May 2001.

URL: https://www.mail-archive.com/search?f=1&l=london-pm%40lists.dircon.co.uk&o=newest&q=from%3A%22Aaron+Trevena%22

The surviving AutoDia project identifies Aaron Trevena as author and maintainer and records copyright from 2001. The project README says AutoDia was previously known as `autodial`, and that it was based on Object-Oriented Perl, Template Toolkit and GraphViz. It remains available as an open-source GitHub project.

Source: hashbangperl/Autodia, README.

URL: https://github.com/hashbangperl/Autodia

This later surviving repository is useful corroboration of the software identity and chronology, but it is not itself evidence that AutoDia was a TermiSoc project. The connection that can be established is that Aaron, who had TermiSoc-hosted personal web space, was developing and publishing AutoDIAL in the same period.

### Devon & Cornwall Linux User Group / open-source activity

A January 2001 London Perl Mongers message by Aaron states that the Devon & Cornwall LUG would help organise a South-West UK Open Source Software conference for local businesses and academia and would participate in the nationwide Linux Day installfest. The message provides contemporary evidence of Aaron's involvement in regional Linux/open-source activity.

Source: London Perl Mongers archive, 21 January 2001.

URL: https://www.mail-archive.com/search?f=1&l=london-pm%40lists.dircon.co.uk&o=newest&q=from%3A%22Aaron+Trevena%22

Aaron's current LinkedIn profile retrospectively states that he attended the University of Plymouth from 1995–2000, was `Termisoc - UPSU Computing and Internet Society : Treasurer and organiser`, and co-founded the Devon & Cornwall LUG with TermiSoc colleague Alex Charrett.

Source: Aaron Trevena LinkedIn profile.

URL: https://uk.linkedin.com/in/aarontrevena

## Interpretation

The strongest new TermiWiki evidence is not a new description on Aaron's current site but the surviving historical web footprint associated with his identity. The repeated `termisoc.org/~betty` signature demonstrates that TermiSoc provided individual web space to Aaron in 2001.

The contemporary messages also show that this personal web identity was used by an active developer involved in Perl, Linux and open-source communities. This gives useful context for the technical culture surrounding TermiSoc, while avoiding the unsupported claim that Aaron's external software projects were TermiSoc projects.

The `~betty` account should be treated as an archaeological target. The original content was not recovered during this search, so its existence and historical use are confirmed, but its actual page contents remain unresolved.
